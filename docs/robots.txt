# This file only became meaningful when the site moved to its own domain. A
# robots.txt is read from the ORIGIN, so while the site was at
# wasabules.github.io/SnmpLens/ the file that governed it was
# wasabules.github.io/robots.txt — which belongs to a user site that does not
# exist. Everything below was served and obeyed by nobody. On snmplens.com it is
# the origin, so it is now the real policy, and the Sitemap line below is a
# discovery route rather than a decoration.

User-agent: *
Allow: /

# The demo is the application itself, built as a bundle. There is nothing in it
# to index — its text is JavaScript — and a crawler spending its budget on a
# 1.5 MB chunk is a crawler not reading the documentation. It also carries
# <meta name="robots" content="noindex">; this saves the fetch as well.
Disallow: /demo/

# Assistants are welcome, and that is a deliberate choice rather than an

# reader it is written for, and a model can only answer with what it was allowed
# to read. The licence is MIT, so nothing here is being given away that the
# repository does not already give away.
